Comandos bash
ls => Lista arquivos e diretórios.
cd  => Alterar diretórios.
  cd (nome_da_pasta) => Entra em uma pasta específica que esta dentro do local atual.
  cd .. => Sobe um nivel na base de pastas.
  cd ~ => Vai até o diretório pessoal(home) do usuário.
  cd - => Retorna para pasta onde você esta antes da última movimentação.
  cd / => vai para o diretório raiz(root).
pwd => Mostra diretório de trabalho.
